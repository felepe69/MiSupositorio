# actividad-git-github
CONCEPTOS FUNDAMENTALES

/Control de versiones: para manejarlas distintas versiones de mis trabajos siempre tenia una version anterior funcional del actual, ya que de darse el caso de que mientras trabajo en el actual falle de cualquier manera tenia mi version anterior de respaldo.
Los principales problemas es que era bastante tosco tener que ir descargando y guardando una version de respaldo para el trabajo y el no saber cuando hacer un respaldo, porque no vas a hacer un respaldo por cualquier minimo cambio que hagas ya que te come mucho tiempo, o en el caso que hayas avanzado mucho sin haber hecho un respaldo porque te olvidaste y el proyecto deja de funcionar, y tu version respaldo esta muy atras de lo que habias avanzado.
Git podria solucionar estos problemas debido a su manera de almacenamiento de versiones, haciendo que sea menos tardado el poder volver a una version anterior y dandote la seguridad de que siempre vas a tener un respaldo en todo momento.
